## Tools

### 🧠 Fable Method — [`fable-method/`](fable-method/)

**Make any AI think like Claude Fable 5 at max effort — instead of guessing.**

The Fable Method is reverse-engineered from how Claude Fable 5 reasons at maximum
effort — its own step-by-step thinking, captured as a portable discipline. It forces an
AI through eight ordered, gated stages and won't let it move to the next step until the
current one passes. Effort scales to the stakes with a rigor dial. Because the method
*is* the intelligence — not the model — it's model-agnostic, and the engine has **zero
dependencies** beyond the Python standard library. Use it the easy way (a drop-in
"skill" — no setup), or the strict way (an MCP server that makes skipping a step
mechanically impossible).
